# Introduction

Dragon-UI is a comprehensive desktop application and CLI tool for tracking Claude Code usage analytics.

## Features

- **Desktop Application**: Beautiful Electron-based GUI with real-time charts
- **CLI Tool**: Full-featured command-line interface for terminal users
- **Multi-Account**: Support for multiple Claude accounts with load balancing
- **Custom Statusline**: 35+ configurable widgets with Powerline support
- **Cost Tracking**: Real-time cost calculations with multi-currency support
- **Session Analytics**: Detailed session tracking and history
